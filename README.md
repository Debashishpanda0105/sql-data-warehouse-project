# 📊 Data Warehouse and Analytics Project

Welcome to the **Data Warehouse and Analytics Project** repository! 🚀

This project demonstrates a complete **Data Warehouse and Business Intelligence (BI)** solution, covering the entire data lifecycle—from raw data ingestion to actionable business insights. It is designed as a portfolio project to showcase industry best practices in **Data Engineering**, **SQL Development**, and **Data Analytics**.

---

# 🚀 Project Overview

This project focuses on building a modern data warehouse using **SQL Server**, integrating multiple data sources, ensuring high data quality, and developing analytical reports that support data-driven decision-making.

---

# 🏗️ Project Requirements

## 📌 Building the Data Warehouse (Data Engineering)

### 🎯 Objective

Develop a modern **SQL Server Data Warehouse** to consolidate sales data from multiple business systems, enabling efficient reporting and advanced analytics.

### 📋 Specifications

- 📂 **Data Sources**
  - Import data from two source systems (**ERP** and **CRM**) provided as CSV files.

- 🧹 **Data Quality**
  - Cleanse, validate, and resolve data quality issues before loading the warehouse.

- 🔄 **Data Integration**
  - Integrate ERP and CRM data into a unified, user-friendly dimensional data model optimized for analytical queries.

- 🎯 **Project Scope**
  - Focus on the latest available dataset.
  - Historical data management (historization) is outside the project scope.

- 📝 **Documentation**
  - Create clear and comprehensive documentation of the data model, ETL process, and project architecture for both technical and business stakeholders.
